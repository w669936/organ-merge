# 合成大器官

面向大学医学社团招新的原创静态网页游戏。11 种透明背景卡通器官、真实组合圆刚体碰撞、接触合成、连锁计分、现场兑奖结算。无需账号、服务器、密钥、广告或运行时外部服务。

## 立即使用

发布使用 `organ-merge-pages.zip`，解压后直接打开 `index.html` 即可在电脑试玩。线上手机入口请按 `GITHUB_PUBLISH_GUIDE.md` 上传 GitHub Pages。**不需要安装软件或执行构建命令。不要把 ZIP 本身当作网站文件上传。**

鼠标移动瞄准、点击释放；手机按住拖动、松手释放。方向键微调、空格投放。360ms 冷却；一次按住只响应一次松手，多指操作不会重复投放。触摸取消不会投放。

两个相同器官真实接触后升级，顺序为：阑尾 → 胆囊 → 甲状腺 → 脾脏 → 胰腺 → 肾脏 → 胃 → 肺 → 心脏 → 肝脏 → 大脑。前十级合成分别加 1、3、6、10、15、21、28、36、45、55 分；两颗大脑接触后消除并加 500 分。顺序未调整，尺寸按插画面积进行了校准，不表示真实解剖比例。

没有时间、步数或器官数量上限。已与容器内物体发生接触的器官，在警戒线上方相对停稳、独立累计危险时间 1.5 秒才判负；回落或高速运动时以两倍速消退。角速度也计入判断，避免正在翻转的物体误判。结束后分数冻结、保留棋盘，向工作人员展示；再玩一次才清零。局中重新开始需要一次确认，避免误触。

声音默认关闭；点击开关后由 WebAudio 即时合成轻柔短音，无背景音乐。声音设置也仅存在当前内存。页面切到后台暂停物理，回到前台不追赶后台时间。

## 开发维护说明（发布或游玩无需执行）

推荐用本地静态 HTTP 服务查看；可在项目目录运行 `python -m http.server 8080`，浏览器打开 `http://localhost:8080/`。双击 HTML 同样可玩。资源全部为相对路径，支持 `/organ-merge/` 子路径。

### 尺寸与物理

修改 `config.js` 的 `organs[].radius`；图片绘制尺寸为 `2 × radius`，碰撞数据按同一尺度缩放，因此**只改尺寸不需要重生成碰撞体**。本版半径：40、43、49、57、75、82、95、103、112、124、135。阑尾等细长轮廓按面积放大，以免难度过低；大脑在 480px 宽棋盘中仍可容纳两枚。

`gravity` 重力、`restitution` 器官反弹、`wallRestitution` 墙地反弹、`friction` 摩擦、`step` 固定时间步、`iterations` 约束次数、`dangerY` 警戒线、`dangerSeconds` 独立危险时间、`restSpeed` 静止阈值、`dropCooldown` 冷却。默认 180Hz（60Hz 显示时每帧 3 子步），每子步 7 次求解。质量随尺寸的 1.45 次幂增长，抑制大小器官极端质量比。

### 分数、奖励与随机

`organs[].points` 表示该等级两枚器官合成时加的分数；最后一项是大脑消除奖励。`rewards` 按 `min` 升序配置称号，默认 0/120/400/900。兑奖以数字分数为准；工作人员可按现场奖品调整门槛。`weights` 只对应初始 1–5 级，默认权重 25/26/24/17/8，不会直接发高级器官。

### 更换图片并生成碰撞体

1. 保留对应的两位编号。准备透明背景 SVG 与 768×768 PNG，主体居中，使用相同构图；网页 WebP 必须与 PNG 具有相同透明轮廓。不要把图片裁切成不同画布。
2. 高分辨率 PNG 放入 `assets/01.png` 等路径；网页图放入对应 `assets/01.webp`；SVG 用于封面或浏览器图标。
3. 维护环境需 Python 3、Pillow、NumPy。运行 `python tools/generate_colliders.py`。该工具直接读取 PNG Alpha，以距离场与贪心覆盖生成内接子圆，写出 `colliders.js`、指标与全部碰撞预览。
4. 检查 `previews/colliders-all.png`：绿色为实际参与物理的子圆，金色为仅作粗筛的包围圆，中心十字标示图像原点。覆盖率约 95%；抗锯齿边缘可能产生约 0.2% 的超出。
5. 本版对复杂形状最多使用 32 个子圆。替换后检查局部边缘与狭长分支，勿只依赖平均覆盖率。打开 `index.html?debug` 可显示图片边界点、子圆、包围圆、中心、当前接触点。
6. 可选：`tools/create_art.py` 重生成全部原创 SVG；使用 Node 的 Sharp 运行 `node tools/raster.cjs` 导出 PNG/WebP。仅素材维护需要这些开发依赖；网页本身不使用它们。

### 自动化测试

Node 18+：`node tests/physics.test.cjs`，包括 11 级合成、穿墙、旋转、堆叠、危险计时、冷却、重开、10/20/30/40 物体负载与 5 轮有种子完整游戏。结果保存为 JSON。

浏览器测试脚本 `tests/browser.test.cjs` 需要开发环境安装 Playwright，并启动静态服务器。`GAME_URL` 可指定子路径网址，`BROWSER_PATH` 可指定 Chrome/Edge 可执行文件。它覆盖鼠标、键盘、真正触摸事件模拟、移动视口、结算、文件协议与资源错误。运行方式及本次实际结果见 `TEST_REPORT.md`。

正常网址不暴露测试接口；只有显式添加 `?debug` 才提供 `window.__ORGAN__`。调试数据仍只存在内存。

## 数据、素材与参考

未使用 localStorage、IndexedDB、Cookie、联网成绩提交、分析统计或第三方追踪。刷新和重开均清空本局。普通网页成绩不具备防篡改签名，适合现场工作人员看屏兑奖。

代码、SVG、布局和合成音效独立制作，没有复制参考游戏素材或源码。参考项目公开说明用于理解固定步长 PBD、组合内接圆和稳定失败规则：[BigNaiWa](https://github.com/YHSome/BigNaiWa)。其排行榜、复活币等机制未引入。参考站 `milkyfrog.com/hecheng` 在本次研究中无法读取。实际验收范围与设备限制见测试报告。
